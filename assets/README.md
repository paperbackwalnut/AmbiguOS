# Identity assets

The mark is an angular A with a displaced crossbar. The primary color is
`#68528e`. Use the single-color mark without effects or a surrounding container.
Keep clear space of at least one stroke width on each side.

* `wordmark.svg`: horizontal lockup for the repository header.
* `logo.svg`: primary mark with a transparent background.
* `logo-black.svg` and `logo-white.svg`: monochrome variants.
* `logo.png`: 512-pixel transparent raster export.

SVG sources and raster exports are covered by the repository license.
